Endpoint 명칭: Creator 로그인
Endpoint 명세: 이메일과 비밀번호를 받아 인증 성공 시 JWT 토큰을 HttpOnly 쿠키에 설정하고 로그인 성공 메시지를 반환한다.
Path: /auth/login/creator 
Method: POST
Request Body: {"email": "creator@mail.com", "password": "secure-password-123"} 
Response Body: {"status": "success", "message": "로그인 성공"} 
Response Headers: Set-Cookie: jwt=...

Endpoint 명칭: 3D Gaussian Splatting 변환 시작
Endpoint 명세: 사용자가 업로드한 최대 10개의 이미지 파일을 받아 Replicate 서비스에 3D 변환 작업을 요청하고, 즉시 작업 ID와 상태를 반환한다.
Path: /splat/convert
Method: POST
Authentication: authenticateToken 필요
Request Body (Multipart/form-data): {"images": "[Array of File Data]"} (파일명: images, 최대 10개)
Response Body: {"status": "processing", "message": "변환이 시작되었습니다.", "jobId": "unique-uuid-v4-id"}
HTTP Status: 202 Accepted

Endpoint 명칭: 3D 변환 작업 상태 확인
Endpoint 명세: jobId를 받아 변환 작업의 현재 상태(processing 또는 completed)를 조회하여 반환한다.
Path: /splat/status/:jobId
Method: GET
Authentication: authenticateToken 필요
Request Parameter: jobId (jobId=uuid-1234)
Response Body: {"jobId": "uuid-1234", "status": "completed"}
